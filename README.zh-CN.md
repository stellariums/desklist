# Desklist

[English](README.md) | 中文

Windows 桌面待办/提醒小工具。无边框桌面底层窗口，最小化到系统托盘，支持定时提醒和周期事件。

Desklist 面向想要“抬手就记、随时可见”的 Windows 用户。你可以快速打开它、立刻记录待办、把它安静地放在系统托盘里，并通过定时提醒和周期事件维持稳定的日常节奏，而不必切到复杂笨重的项目管理软件。

相比功能臃肿的待办应用，Desklist 更强调桌面原生体验：简洁的毛玻璃界面、列表与日历双视图、本地 SQLite 存储、轻量提醒能力，以及更贴近日常工作的使用方式。

## 功能

- 事件创建、编辑和安全删除，支持标题、描述、安排时段和独立的可选截止时间
- 四种筛选视图：今天 / 未完成 / 已完成 / 全部
- **日历视图**：标题栏切换按钮在列表与日历视图间切换；有未完成事项的日期显示圆点；点击日期查看当天事项
- 定时提醒：到期提醒 + 可选提前提醒（5/15/30/60 分钟或 1 天前）
- 周期事件：每天、每周、每月，支持设置截止时间
- 完成周期事件后自动生成下一次
- 系统托盘常驻，关闭窗口可隐藏到托盘
- 单实例运行
- 深色毛玻璃 UI（Windows Acrylic）
- 首次启动可选择任务数据保存位置，不再强制占用系统盘
- 设置页可查看并打开当前数据文件夹
- 本机浏览器工作台，可查看、新建、编辑、完成和恢复任务
- 收件箱支持先快速收集任务，之后再安排日期和时间
- 今日首页集中展示当天安排、历史逾期和收件箱状态
- 复盘页支持周视图和月视图，可按周期翻页、回到今天并联动查看每日详情
- 受令牌保护的本机 Agent REST API 和 MCP，可由 Codex、Claude、Hermes 等工具安全管理任务

## 数据保存

首次启动时，Desklist 会让你选择任务数据保存在哪个文件夹。如果电脑中已经存在旧版任务，程序会先安全复制并检查完整，再启用新位置；原来的数据库不会自动删除。

软件升级或重新安装不会覆盖你选择的数据文件夹。请不要在 Desklist 运行时手动移动或修改 `desklist.db`、`desklist.db-wal` 和 `desklist.db-shm`。

## 技术栈

- 前端：Vue 3 + TypeScript + Vite
- 桌面框架：Tauri 2
- 数据存储：SQLite（Rust `sqlx` 统一管理）
- 提醒调度：Rust + Tokio
- 通知：`tauri-plugin-notification`

## 开发

```bash
# 安装依赖
npm install

# 开发模式
npm run tauri dev

# 生产构建
npm run tauri build
```

## 开发路线

浏览器个人工作台、受保护的 Agent REST API 和 Streamable HTTP MCP 已完成，下一阶段进入真实 Agent 联调。已完成内容、开发顺序和暂不开发范围见[个人工作台路线图](docs/ROADMAP.zh-CN.md)。Agent API/MCP 的令牌获取方式和调用示例见[本机 Agent 接入文档](docs/AGENT_API.zh-CN.md)。

## 浏览器工作台

Desklist 运行后，可通过托盘菜单 `Open Browser Workbench` 打开浏览器工作台，也可以直接访问 `http://127.0.0.1:47831`。当前可把尚未确定时间的事项快速放入收件箱，之后再安排进日历，并单独设置可选截止时间；同时支持任务编辑、完成、恢复和回收站安全删除。

网页服务只监听本机地址，局域网和公网中的其他设备无法访问。
