# Desklist 个人工作台路线图

更新时间：2026-08-29

## 已完成

- 支持首次启动时选择任务数据保存位置，不再强制占用系统盘。
- 能把旧版数据库安全复制到新位置，并在确认完整后再启用；旧数据库不会自动删除。
- 设置页会显示当前数据位置，点击即可打开对应文件夹。
- 任务的新建、修改、完成、恢复、删除、重复任务和提醒逻辑已统一放到 Rust 后台，前端不再直接操作数据库。
- 提醒程序和界面共用同一份数据库连接，避免不同入口出现不同结果。
- 增加临时数据库自动测试，不会使用或改动用户的真实任务。
- Windows 前端构建、Rust 测试和 NSIS 安装包构建均已通过。

## 下一阶段：浏览器工作台

计划从 2026-08-30 继续，按以下顺序推进：

1. 建立本机网页服务，让浏览器可以打开 Desklist，同时保留托盘和系统提醒。
2. 重构“今日”首页，展示今日安排、临近截止和快速新建。
3. 增加收件箱、未完成、已完成和回收站导航。
4. 把任务的“截止时间”和“安排时段”分开，并安全迁移旧任务时间。
5. 增加周视图和月视图，方便安排个人时间。
6. 将界面改为简约杂志风：暖色背景、清晰排版、少装饰、支持浅色和深色。

## 后续阶段：Agent 接口

浏览器工作台稳定后再继续：

1. 提供本机 REST/OpenAPI，支持查询、新建、修改、完成和恢复任务。
2. 使用独立令牌保护 Agent 写入，并记录每次修改来源。
3. 删除任务先进入回收站，避免 Agent 误删后无法恢复。
4. 提供 HTTP MCP 和 stdio 桥，供 Codex、Claude、Hermes 等本机 Agent 使用。

## 暂不开发

- 云同步、局域网和公网访问
- 多人协作与账户系统
- 项目、标签、笔记和插件平台
- Android 版本

这些方向只有在个人工作台和 Agent 接口稳定后，才重新评估。
