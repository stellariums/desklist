# Desklist 个人工作台路线图

更新时间：2026-08-30

## 已完成

- 支持首次启动时选择任务数据保存位置，不再强制占用系统盘。
- 能把旧版数据库安全复制到新位置，并在确认完整后再启用；旧数据库不会自动删除。
- 设置页会显示当前数据位置，点击即可打开对应文件夹。
- 任务的新建、修改、完成、恢复、删除、重复任务和提醒逻辑已统一放到 Rust 后台，前端不再直接操作数据库。
- 提醒程序和界面共用同一份数据库连接，避免不同入口出现不同结果。
- 增加临时数据库自动测试，不会使用或改动用户的真实任务。
- Windows 前端构建、Rust 测试和 NSIS 安装包构建均已通过。
- 已建立仅限本机访问的网页服务，可通过浏览器查看今日、未完成、已完成和全部任务。
- 托盘菜单可以直接打开浏览器工作台；浏览器现已支持新建、编辑、完成和恢复任务。
- 浏览器页已形成左侧导航、任务月历、日期复盘和下一步建议的工作台骨架，并为业务数据与后续工具预留入口。
- 已完成回收站数据流程；桌面版和浏览器版删除都会先软删除，浏览器支持恢复和二次确认后彻底删除。
- 已完成收件箱数据流程；未安排任务不进入日历和提醒队列，安排日期后自动转为普通任务。
- 已完成“今日”默认首页，集中展示今日安排、历史逾期、收件箱状态，并提供快速新建和导航入口。
- 已将任务的安排开始、安排结束和可选截止时间分开；旧任务保留原安排且不虚构截止时间，周期任务会同步平移这些时间。
- 已完成复盘页的周视图和月视图；支持按周/月翻页、跨月周区间、回到今天和每日详情联动。
- 已完成浏览器工作台的整体视觉精修；统一纸张式杂志风层级、卡片和交互状态，并优化窄屏摘要、空状态和弹窗显示。

## 浏览器工作台：基础阶段已完成

2026-08-30 已完成浏览器工作台的本机服务、基础页面、任务操作、回收站、收件箱、今日首页、时间语义拆分、周/月视图和视觉精修。浏览器工作台基础阶段完成，下一步进入 Agent 接口阶段。

## 下一阶段：Agent 接口

浏览器工作台基础阶段完成后按以下顺序继续：

1. 提供本机 REST/OpenAPI，支持查询、新建、修改、完成和恢复任务。
2. 使用独立令牌保护 Agent 写入，并记录每次修改来源。
3. 删除任务先进入回收站，避免 Agent 误删后无法恢复。
4. 提供 HTTP MCP 和 stdio 桥，供 Codex、Claude、Hermes 等本机 Agent 使用。

## 暂不开发

- 云同步、局域网和公网访问
- 多人协作与账户系统
- 项目、标签、笔记和插件平台
- Android 版本
- 浏览器工作台深色模式

这些方向只有在个人工作台和 Agent 接口稳定后，才重新评估。
